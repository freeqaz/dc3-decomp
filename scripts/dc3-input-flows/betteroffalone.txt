# Better Off Alone — Full DTA flow from boot to gameplay
#
# Same flow as ymca.txt but scrolls to "Better Off Alone" in the song list.
# Better Off Alone is list index 4: two downs from where perform mode opens.

# attract_screen plays videos/intro.bik (83 s) since desktop movies open out
# of the archive (PLAN G-15; before, the open failed and the screen advanced on
# its first poll).  Skip it as a player does: wake (movie_overlay_panel's enter
# exits controller mode), then confirm on the overlay's SKIP item.  Under
# DC3_FAST_BOOT both presses land on autosave_warning_screen, which advances by
# itself either way.
wait_screen attract_screen
+28 wake
+30 confirm

wait_screen title_screen
+30 confirm

wait_screen main_screen
+30 confirm

wait_screen choose_mode_screen
+30 confirm

# Song select -- by NAME: `highlight betteroffalone` presses down/up until the
# list's highlight is on it (engine Joypad_Native.cpp, dc3
# JoypadSelect_Native.cpp), so the flow plays Better Off Alone whatever rows
# precede it (downloadable songs, PLAN D-3).  On the disc alone the list reads
#   0 playlists  1 random_song  2 song_tier_0  3 ymca  4 betteroffalone
# from the entry focus 2, i.e. two downs.  Counting downs is how this flow
# went wrong before: the old FIVE downs never selected Better Off Alone (with
# the invented `- 1` scroll edge they jumped the tier header, without it they
# landed on index 7), and every run of pose_scoring_gate.sh and
# test_lighting_events.sh before that fix scored and lit Starships.
wait_screen song_select_screen
+30 highlight betteroffalone
+60 confirm

# multiuser_screen: controller input, as on the 360 (see ymca.txt):
# difficulty, `play`, `skip_waiting` -> start_game -> enter_gameplay.
# The difficulty is EASY -- one down from the highlighted `beginner`
# (seldiff list: beginner, easy, medium, expert).  pose_scoring_gate.sh
# needs a non-Beginner difficulty: MoveDir::ResetDetectFrames builds no
# scheduled detect frames for Beginner (Beginner is rated by the async
# detectors only), so its ham2 DetectFrac samples all read
# branch=no-move-key and the gate has nothing to measure.  Easy is what this
# flow played before multiuser_screen became controller-driven (1ac79728d):
# the auto-fired path kept HamPlayerData's default difficulty, 0 = Easy.
wait_screen multiuser_screen
+40 down
+110 confirm
+180 confirm
+250 confirm
