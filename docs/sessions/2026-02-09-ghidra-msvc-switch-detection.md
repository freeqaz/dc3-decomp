# Ghidra MSVC Switch Detection Implementation

**Date**: 2026-02-09
**Goal**: Implement switch table detection for Xbox 360 MSVC binaries in Ghidra's PowerPCAddressAnalyzer

## Problem Summary

Ghidra's `PowerPCAddressAnalyzer` doesn't detect switch tables generated by Xbox 360 MSVC. The analyzer expects GCC/Clang-style absolute address tables, but MSVC generates **relative offset tables with 16-bit entries**.

### MSVC Pattern (What DC3 Uses)

```asm
; Index: 536-548 in BustAMovePanel::OnBeat
lwz        r11, 0x3c, r30       ; Load switch variable (mState)
cmplwi     cr6, r11, 0x9        ; Bounds check: if (var > 9) goto default
bgt        cr6, default_case    ; Guard branch
lis        r12, jumptable       ; Load jump table address (high)
slwi       r0, r11, 1           ; Index * 2 (halfword entries)
addi       r12, r12, jumptable  ; Load jump table address (low)
lhzx       r0, r12, r0          ; Load 16-bit OFFSET from table
lis        r12, base_addr       ; Load base address (high)
addi       r12, r12, base_addr  ; Load base address (low)
nop                             ; Alignment
add        r12, r12, r0         ; target = base + offset
mtctr      r12                  ; Move to count register
bctr                            ; Branch to CTR
```

**Key differences from standard pattern:**

| Feature | MSVC (DC3) | GCC/Clang |
|---------|-----------|-----------|
| Table entry size | 16-bit (`lhzx`) | 32-bit (`lwzx`) |
| Address type | Relative offset | Absolute address |
| Computation | `base + offset` | Direct load |

### Why Current Detection Fails

The `SwitchEvaluator.evaluateReference()` method (line 465) expects:
```java
if (!((refType.isComputed() || refType.isConditional()) &&
    program.getMemory().contains(address))) {
```

For MSVC tables:
1. The `lhzx` loads an **offset** (e.g., 0x100), not an address
2. This offset (0x100) is not a valid memory address, so it's ignored
3. The final `add` computes the target, but symbolic execution may not track it correctly

### Phase 1: Pattern Detection

Add MSVC switch pattern detection to `SwitchEvaluator`:

```java
// Add fields to SwitchEvaluator
private boolean isMSVCPattern = false;
private Address tableBaseAddress = null;
private Address codeBaseAddress = null;
private int entrySize = 4;  // Default 4 bytes (lwzx), MSVC uses 2 (lhzx)

@Override
public boolean evaluateContext(VarnodeContext context, Instruction instr) {
    String mnemonic = instr.getMnemonicString();

    // Existing cmplwi detection (lines 423-450)
    // ...

    // NEW: Detect lhzx pattern (MSVC halfword table)
    if (mnemonic.equals("lhzx")) {
        isMSVCPattern = true;
        entrySize = 2;

        // Extract table base from instruction operands
        // lhzx rD, rA, rB -> table base is typically in rA
        Register tableReg = instr.getRegister(1);
        if (tableReg != null) {
            RegisterValue regVal = context.getRegisterValue(tableReg);
            if (regVal != null && regVal.hasValue()) {
                tableBaseAddress = program.getAddressFactory()
                    .getDefaultAddressSpace()
                    .getAddress(regVal.getUnsignedValue().longValue());
            }
        }
    }

    // NEW: Detect add after lhzx (code base computation)
    if (isMSVCPattern && mnemonic.equals("add")) {
        // add rD, rA, rB where rA is code base, rB is offset from table
        // The result goes to mtctr
        Register baseReg = instr.getRegister(1);
        if (baseReg != null) {
            RegisterValue regVal = context.getRegisterValue(baseReg);
            if (regVal != null && regVal.hasValue()) {
                codeBaseAddress = program.getAddressFactory()
                    .getDefaultAddressSpace()
                    .getAddress(regVal.getUnsignedValue().longValue());
            }
        }
    }

    return false;
}
```

### Phase 2: Target Address Computation

Override target collection to compute addresses from offsets:

```java
@Override
public boolean evaluateReference(VarnodeContext context, Instruction instr, int pcodeop,
        Address address, int size, DataType dataType, RefType refType) {

    // Existing logic (lines 465-479)
    // ...

    // NEW: For MSVC pattern, compute target from offset
    if (isMSVCPattern && refType.isRead() && codeBaseAddress != null) {
        // The 'address' here might be the table entry address
        // We need to read the offset value and add to code base
        try {
            long offset;
            if (entrySize == 2) {
                offset = program.getMemory().getShort(address) & 0xFFFF;
            } else {
                offset = program.getMemory().getInt(address) & 0xFFFFFFFFL;
            }

            Address targetAddr = codeBaseAddress.add(offset);
            if (program.getMemory().contains(targetAddr) &&
                !targetList.contains(targetAddr)) {
                targetList.add(targetAddr);
            }
        } catch (MemoryAccessException e) {
            // Ignore
        }
    }

    return super.evaluateReference(context, instr, pcodeop, address, size, dataType, refType);
}
```

### Phase 3: Manual Table Traversal

Add fallback method to directly read table entries when symbolic execution doesn't work:

```java
private void recoverMSVCSwitchTable(Program program, Address bctrAddr,
        Address tableBase, Address codeBase, int tableSize, int entrySize,
        TaskMonitor monitor) {

    ArrayList<Address> targets = new ArrayList<>();
    Memory mem = program.getMemory();

    for (int i = 0; i <= tableSize; i++) {
        try {
            Address entryAddr = tableBase.add(i * entrySize);
            long offset;

            if (entrySize == 2) {
                offset = mem.getShort(entryAddr) & 0xFFFF;
            } else {
                offset = mem.getInt(entryAddr) & 0xFFFFFFFFL;
            }

            Address targetAddr = codeBase.add(offset);
            if (mem.contains(targetAddr)) {
                targets.add(targetAddr);
            }
        } catch (MemoryAccessException e) {
            break;
        }
    }

    if (targets.size() > 1) {
        AddressTable table = new AddressTable(bctrAddr,
            targets.toArray(new Address[0]),
            program.getDefaultPointerSize(), 0, false);
        table.fixupFunctionBody(program,
            program.getListing().getInstructionAt(bctrAddr),
            monitor);
        labelTable(program, bctrAddr, targets);
    }
}
```

private MSVCSwitchInfo detectMSVCPattern(Program program, Address bctrAddr) {
    Listing listing = program.getListing();

    // Walk backwards from bctr to find pattern
    // bctr <- mtctr <- add <- (lis/addi base) <- lhzx <- ...

    Instruction instr = listing.getInstructionAt(bctrAddr);
    if (instr == null || !instr.getMnemonicString().equals("bctr")) {
        return null;
    }

    // Look back up to 15 instructions
    Address addr = bctrAddr;
    for (int i = 0; i < 15; i++) {
        instr = listing.getInstructionBefore(addr);
        if (instr == null) break;
        addr = instr.getMinAddress();

        String mnem = instr.getMnemonicString();

        // Found lhzx - this is MSVC pattern
        if (mnem.equals("lhzx")) {
            return extractMSVCSwitchInfo(program, bctrAddr, instr);
        }

        // Found lwzx - standard pattern, not MSVC
        if (mnem.equals("lwzx")) {
            return null;
        }
    }

    return null;
}

## Implementation Notes

### Why Modify Analyzer vs Script?

**Analyzer (chosen approach)**:
- Runs automatically during analysis
- Works on all functions
- Integrates with decompiler
- Switch tables appear correctly in CFG

**Script**:
- Manual invocation required
- Doesn't integrate with auto-analysis
- Could work as proof-of-concept first

### Backward Compatibility

Changes should:
1. Not affect GCC/Clang pattern detection
2. Only trigger for MSVC pattern (lhzx + add)
3. Fall through to existing logic if detection fails

### Known Edge Cases

1. **Nested switches** - Multiple bctr in same function
2. **Default-only** - Tables with fallthrough to default
3. **Computed defaults** - Default case isn't last
4. **Variable table sizes** - May need to read table until invalid address

## Reference: Current Ghidra Behavior

### SwitchEvaluator Key Methods

| Method | Purpose |
|--------|---------|
| `evaluateContext()` | Detect cmplwi, track bounds |
| `evaluateReference()` | Collect computed addresses |
| `unknownValue()` | Provide assumed index values |
| `evaluateDestination()` | Stop at target bctr |

### Symbolic Execution Flow

```
1. Start from code block containing bctr
2. For assume = 0 to tableSize:
   a. Set assumeValue = assume
   b. Flow constants through block
   c. Collect addresses from evaluateReference
3. Create AddressTable with collected targets
4. Fix function body with new edges
```
