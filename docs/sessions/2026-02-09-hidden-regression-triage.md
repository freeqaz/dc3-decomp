## Key Findings

### StackString root cause (`ca723ac0`)
Commit changed base class order in `src/system/utl/Str.h` from `class StackString : public FixedString, public TextStream` to `class StackString : public TextStream, public FixedString`. This affects vtable layout and constructor codegen for all 6 instantiations. Single header revert fixes all 6.

### Commit `24106e15` is the biggest offender
19 of 70 regressions came from this single commit ("code", 2026-02-05). Many are curl functions and CharSignalApplier-related. The commit likely made broad header or struct changes that rippled across many TUs.

### Commit `325e8fcf` (merge main into dev) introduced 6 regressions
These are merge-induced regressions in HamMove, trie, MoveVariant, MoveDir, AllocInfo. May be resolvable by checking what main-branch changes conflicted.

### Commit `747f824f` (revert commit) introduced 5 regressions
Ironic: a revert intended to fix regressions introduced 5 new ones in SkeletonClip, Sound, HamDirector, Skeleton, RndParticleSys.
