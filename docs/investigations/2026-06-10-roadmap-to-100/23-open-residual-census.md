## Summary

The wave-5 plan estimated 459 open functions. The live DB confirms exactly
**459 functions / 213,648 bytes** open in `authorable_done`. No revision down to
396 is supported by the data; the estimate and the DB agree.

A material slice of the "open" set is a **promotion / DB-staleness artifact, not
real residual work**: 170 functions (18,800 bytes) carry `verdict='COMPLETE'` and
`unicorn_verdict='EQUIVALENT'` with `current_percent=100.0`, but their
`match_percent_normalized` column is NULL/0, so the view classifies them `open`.
These are matched functions whose normalized score was never written. Running
`python3 scripts/sync_match_percent.py --build --promote` from repo root should
populate `match_percent_normalized` and move them to `matched`, dropping the open
count by ~170 / ~18.8K bytes. **This is the single highest-leverage Wave-6 action.**

## Anomalies / High-Priority Investigation Targets

1. **`RndPropAnim::ForeachKeyframe` (0.5%, 2,468 B, AT_LIMIT, no unicorn class)** —
   near-zero normalized match. Either a wrong symbol pairing in the DB or a
   function whose source is structurally wrong. `current_percent=0.43`, so it is a
   genuine near-zero, not just a normalization gap. Run `run_objdiff` to diagnose.

2. **`MemAlloc` (1.5%, 1,172 B, call_count)** — near-zero with a call-count
   divergence; likely a wrapping/delegation mismatch (the native allocator path vs
   the original). High value if fixed (core allocator).

3. **`math/mtx::Invert` (70.7%, cap_exhausted_decomp, 2,800 B)** — source causes
   the divergence. Ghidra decompile + full rewrite from asm is the approach.

4. **`rndobj/Shader` (11 fns, avg 42.9%)** — wildly below average. Multiple
   `CalcShaderOpts` variants are `wild_jump_match`; the switch dispatch table is
   likely mismatched. Run vtable dumps per shader class to fix slot ordering.

5. **The 170 COMPLETE/EQUIVALENT promotion artifacts** — not an investigation
   target so much as a one-command win; see Routable §A.

## Appendix — milo-tests run methodology (reproducible)

The full `milo-tests` binary contains **412 tests** (`--gtest_list_tests | grep -c`).
A bare `milo-tests` invocation **does not run to completion** on either the main
binary or the wave5 binary:

1. **Crash (pre-existing, exists on main):** `AssetLoadingTest.LoadDirectorSubdir`
   SIGSEGVs *when run after the rest of the `AssetLoadingTest` suite* (specifically
   after `LoadFullVenueWorlds`). It is a **state leak in the full AssetLoadingTest
   suite** — `LoadFullVenueWorlds` then `LoadDirectorSubdir` **pass in isolation**
   on the main binary, but the full `AssetLoadingTest.*` run dies at
   `LoadDirectorSubdir`. Reproduced on `dc3-decomp/native/build/milo-tests` (main).
2. **Hang (pre-existing):** `ObjectLifetimeUnitTest.CascadeDeleteNamedSubdirsNullsExternalDirPtrsWithoutCrash`
   is a gtest **death test** that uses `fork()` in a 7-thread context and hangs.

**Reproducible filtered run** (excludes only the crashing + hanging tests):

```bash
cd /home/free/code/milohax/dc3-decomp/orig-assets
.../native/build/milo-tests \
  --gtest_filter='-AssetLoadingTest.LoadDirectorSubdir:ObjectLifetimeUnitTest.CascadeDeleteNamedSubdirsNullsExternalDirPtrsWithoutCrash'
```

**wave5 binary result (this branch):**
`[==========] 410 tests ... ran. → [ PASSED ] 323 / [ SKIPPED ] 85 / [ FAILED ] 2`
(exit code 1). The 85 skips are GPU/headless/replay suites that self-skip without a
device or assets.

The **2 failures are pre-existing and untouched by Lane D** (both fail identically
on the main binary in isolation: 0 PASSED / 2 FAILED):

- `ObjectLifetimeTest.MergeDirsMoveAllSubdirsTransfersOwnership` — kMoveAllSubdirs
  filter does not remove subdirs from the source dir in MergeObjectsRecurse.
- `MeshVertexLoading.CompressedSkinningMatchesCpuSkinningForSyntheticBones` —
  synthetic-bone skinning parity (distinct from the
  `CompressedSkinnedDecodePreservesBoneWeightsAndIndices` test that Lane C fixed).

**Lane D's five fixed tests all pass in the same filtered run:**
`RndCamProjectionTest.*` (10/10) and
`MergeScopeParityUnitTest.NonProxyPipelinePreservesNestedReplaceSubdirScope`.
